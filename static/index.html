Field Glossary

Core ASM
# — Record index (chronological order)
Prompt — Input text analyzed
Cat — Category label (benign, mild, harmful, jailbreak, etc.)
Role — Source role (user prompt or model response)
Tok — Token count (sequence length)
Stress — Alignment stress score. Total correction pressure across discriminative middle layers. Higher = model working harder to maintain alignment
Net — Net correction. Signed sum of per-token attribution. Positive = net reinforcement of alignment direction
Ent — Entropy of the correction distribution. High = correction spread evenly across tokens. Low = concentrated on a few tokens
Int% — Interior share. Fraction of correction attributed to interior (non-boundary) tokens. Higher values indicate the model is responding to semantic framing
IntCV — Interior coefficient of variation. How unevenly correction is distributed among interior tokens. High = a few interior tokens dominate
Bnd% — Boundary share. Fraction of correction at first and last tokens. Complement of Int%
KL — KL divergence between instruct and base model next-token distributions. Higher = alignment training changed the output more at this prompt
Neg — Count of tokens with negative attribution (pushing against the alignment correction)
Model Predictions
InstTop1 — Most likely next token predicted by the instruct (aligned) model
InstP — Probability the instruct model assigns to its top prediction
BaseTop1 — Most likely next token predicted by the base (unaligned) model
BaseP — Probability the base model assigns to its top prediction
Lateral Tension Profile (LTP)
M — Mean lateral tension magnitude across all tokens. How much the alignment correction displaces probability mass toward alternative tokens
MaxPRC — Maximum probability reallocation at any single token (in percentage points)
N_dir — Number of tokens with directional (non-flat) tension profiles
Spectral Field Density (SFD)
Dens — QK routing density. How many dimensions of the attention routing subspace each token engages on average
Rank Displacement
Tau — Kendall tau correlation between base and instruct alternative token orderings. 1.0 = identical ranking, lower = RLHF reordered the priority structure
Ovlp — Overlap. Fraction of top-k alternative tokens shared between base and instruct models
Entropic Cascade Mitigation (ECM)
ecm — Detector replay over the extracted per-token traces (stress always; KL when its checkbox is on; density when SFD collection is enabled in Configuration). Reports, per channel, where the cascade detector would have fired and how hard (σ-excess), with index-aligned per-token signals. Replay only — analysis mode never actuates. Detector parameters come from the ECM settings in Configuration
